# SCIENCE PORTFOLIO — Варіант 9

Вебзастосунок для формування портфеля науково-дослідних проєктів за допомогою класичного та модифікованого МАІ і багатокритеріальної оптимізації.

## Технології
- React + Vite — клієнтська частина
- Node.js + Express — серверна частина та API
- JavaScript — алгоритми МАІ, оцінювання узгодженості й оптимізація
- Recharts — діаграми

## Запуск у Windows
Потрібен встановлений Node.js (рекомендовано LTS).

1. Розпакуйте архів.
2. Відкрийте папку `science-portfolio` у терміналі або PyCharm / VS Code.
3. Встановіть залежності:

```bash
npm run install:all
```

4. Запустіть frontend і backend одночасно:

```bash
npm run dev
```

5. Відкрийте адресу, яку покаже Vite, зазвичай `http://localhost:5173`.

Backend працює на `http://localhost:5000`.

## Реалізовані можливості
- Реєстр проєктів: додавання, видалення, редагування параметрів та оцінок.
- Матриця попарних порівнянь критеріїв за шкалою Сааті; автоматичне заповнення оберненої величини.
- Класичний МАІ: геометричні середні, нормалізація, CI та CR.
- Модифікований МАІ: коригування ваг з урахуванням надійності експерта, невизначеності та стратегічних ваг.
- Бінарна оптимізаційна модель із бюджетними, кадровими, обладнаннєвими та конфліктними обмеженнями.
- Таблиця результатів, порівняльна діаграма пріоритетів, діаграма фінансування за напрямами.
- Експорт звіту у Markdown.

## Примітка щодо оптимізації
Для навчального реєстру використовується точний перебір бінарних комбінацій. Він гарантує найкращий знайдений портфель за заданою моделлю, але обмежений 22 проєктами через експоненційне зростання кількості комбінацій. Для великих реєстрів доцільно підключити спеціалізований MILP solver.
